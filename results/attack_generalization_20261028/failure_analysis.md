# 当前结论与限制

含SVD主方法独立准确率：MNIST99.61%、SVHN96.98%、DTD76.12%；原专家为99.69%、97.46%、79.41%。DTD损失3.30个百分点，保留原记录。

输出校正已有部分恢复；去SVD三任务约50%、50–51%、53–57%，不能只引用未校正的类别0低分来声称不可恢复。校正对无保护模型也可能有损，必须匹配比较。

MNIST的B+b-only独立只有9.80%，是功能保持失败的删项，不是成功防御。A-only独立99.70%，融合/AGA约99.3%，没有保护。它是删除主发布B侧，不是另行优化的A-only。

当前去SVD在三个任务未显示独立精度更差，不能预先声称SVD的分类收益已证。公开替换、随机噪声及非AGA匹配的新结果待运行，不预填准确率。
