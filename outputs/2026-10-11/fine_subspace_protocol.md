# 细粒度子空间：先检查分离与替换

本轮固定 Cars 第 9–11 层，仅检查 QKV 投影、MLP 上投影和下投影的八个神经元坐标。该区域来自之前只用目标专家进行的任务定位，不重新遍历十二层。复用 NUFILT 原版 SVD、SciPy 广义特征值求解及既有作者评价／融合／AGA 入口；这些工具和低活动方向扰动均不声明为创新。

使用公开 Cars、MNIST、DTD 训练图片，各 128 张估计、128 张确认。两部分不重叠，并排除本项目已用的对应训练索引。全部图片仅提供前向激活，不用标签选方向。MNIST／DTD 提供已知分布先验，不能据此声称未知分布泛化；对应专家权重不参与方向或参数构造。

对每个矩阵的输入 z，以目标校准均值 μ 中心化。QKV 与 MLP 上投影的候选输入方向限制在目标任务向量 99% 奇异能量右子空间的补空间内，并显式排除 LayerNorm 仿射约束导致的精确零方向。下投影先按两个其他分布的最低响应比选八个神经元，再在这些坐标内求方向；这一族不声明为 NUFILT 奇异补空间。

令 Cₜ 为目标输入的中心二阶矩，Cₒ 为两个其他分布相对目标均值的平均二阶矩，Π 为声明的候选空间。求 ΠᵀCₒΠ 与 ΠᵀCₜΠ＋ρI 的最大广义特征方向，ρ 为目标投影平均能量的 0.001 倍。独立确认要求：两个其他分布的局部 RMS 响应均至少是目标的 4 倍，且目标确认／估计能量比在 0.5–2 范围内。保留未通过方向，零后处理构造也属于有效的预检负结果。

方向冻结后才加载未来专家。替换预检使用此前已经观察过的 Cars 2048 张训练确认数据，不冒称独立测试。完整替换 QKV／上投影矩阵和偏置，下投影替换选中的八列及偏置；同时检查全部通过方向的实际编辑支持并集。原始专家、固定组与并集均测独立和八专家 TA，系数 0.2。

对支持内任何编辑，完整公开支持替换满足 R(θ′)=R(θ)，因此实测替换融合准确率是该家族的条件恢复下限。如果并集相对未保护融合的最大可能下降不足 5 pp，停止构造。这是预先固定的安全效果筛选，不是仅按 0.5 pp 独立损失淘汰；也不是证明高于该下限就存在防御。基准恢复下限决定是否继续实验，不用于方向或扰动参数拟合，不能把研究筛选过程称作完全不看融合基准。

只有通过上述必要条件，才测试一个固定均值补偿秩一候选：ΔWⱼ = α‖Wⱼ‖ᶠuⱼvⱼᵀ，Δbⱼ = −ΔWⱼμⱼ。u 使用目标任务向量的输出方向，v 使用冻结输入方向。联合幅度只根据目标校准图像的中心差分特征响应确定，特征 RMS 预算 0.01，矩阵相对改变量上限 0.1；不搜索幅度，不响应重建，不梯度微调。

局部输入响应分离不保证最终分类、融合或抗恢复；均值补偿秩一扰动也不是新机制。若构造进入有限验证，则 Cars 独立与 Cars／MNIST／DTD 八专家融合使用完整官方测试集；原版 AGA、整组 Attention、整组 MLP、精确支持替换与不攻击都有未保护同条件对照。最佳恢复包含不攻击。完整报告性能与安全权衡，保留 0.5 pp 性能参考，不从测试集重调参数。

配置与源码在 GPU 运行前冻结，运行上限 900 秒；原始激活、方向、权重、预测与完整日志只留服务器。本地和 Git 保留轻量协议、计数、核验与图表。
