# 任务补空间后处理

目标：已有专家不再微调，保留本任务计算，只在补空间修改参数，使融合后出现干扰。构造与参数选择均不能读取未来伙伴。[老师要求](teacher_feedback.md)依据用户本次重贴的录音转写整理。

## 已有结果

| 构造 | 独立 MNIST | 直接融合 MNIST | 同条件 AGA 后 MNIST |
|---|---:|---:|---:|
| 单层随机补空间 | 99.69 → 99.70 | 99.37 → 8.92 | 99.30 → 99.29 |
| 六处有符号补空间 | 99.69 → 99.68 | 94.00 → 91.91 | 93.23 → 91.01 |

第一行是双任务、系数 0.5；第二行含八个专家、系数 0.2，只评估 MNIST/SVHN。两行不能直接比较。第一行的方向只用目标数据，但从 16 个预设中选择幅度和位置时使用了已知 SVHN 开发融合，不能称未知伙伴验证。第二行不使用伙伴构造，但公开 PCA 清理后达到 93.48%，同条件对照 93.92%，仍不够。

内部压缩曾取得更强的 AGA 干扰，但改变了任务计算，不作为“只改补空间”的成果。历史结果仍留在 Git 和服务器归档，不再保留其运行入口。

## 保持条件

目标校准输入均值为 μ，估计主空间投影为 P，Q=I−P。后处理为

\[
W'=W+RQ,\qquad b'=b-RQ\mu.
\]

输入 x 的局部输出变化是 RQ(x−μ)。只有 x−μ 在 P 内时严格为零；未见图片、分类结果和融合模型均须实测。

[NUFILT](https://arxiv.org/html/2509.21413v2)的子空间对齐有谱间隔、误差与秩条件，其完整方法还优化 LoRA。我们只复用了 SVD，不是完整复现。任务向量的高能量方向、输入 PCA 方向和分类必需方向不能混为一谈。

## AGA 为什么能恢复

对于 PyTorch 每头权重 A，作者求解 AᵀT≈A₀ᵀ，再返回 TᵀA。理想无正则、精确最小二乘给出

\[
A_{\mathrm{rec}}=A_0\Pi_{\mathrm{row}(A)},
\]

即把公开 anchor 投影到发布权重的行空间。大范数扰动并不会原样留下。实际作者代码含 10⁻⁸ 正则与 FP32 转换，不能将理想公式当分类保证。MLP 用余弦配对，恢复机制不同。[论文](https://arxiv.org/html/2606.30360v1)、[固定版本源码](https://github.com/krumpguo/secure-merge-attack/blob/fb61429f5e6f3517102d506697a150ac26abbdea/utils_attack_B32.py)。

边界也很明确：对于上述线性编辑，知道准确 P、μ 的补空间清理能把保护与未保护变成同一组参数。不能把更换噪声方向说成解决了清理问题；这个边界也不证明所有补空间方法都不可能。按老师本次强调的顺序，先检验具体的计算干扰，再交代恢复边界。

## 一个固定 Q/K 候选

仅修改第一层 Attention 的 Query、Key。P 是目标输入中心化 PCA 基，v 与 P 正交，g(x)=vᵀ(x−μ)。每个头选择一个单位输出方向 u，写入

\[
q'_i=q_i+\alpha u g_i,\qquad k'_j=k_j-\alpha u g_j.
\]

权重增量为 ±αuvᵀ，bias 对应补偿 ∓αuvᵀμ。若 x−μ 在 P 内，g=0，原计算保持。对头维度 d=64，Attention 分数的变化是

\[
\Delta s_{ij}=\frac{\alpha g_i u^\top k_j-\alpha g_jq_i^\top u-\alpha^2g_ig_j}{\sqrt d}.
\]

区别于旧 V/MLP 输出噪声：Q/K 在同一个分数中相乘，出现跨 token 二次项。它仍是线性权重编辑，不声称抵抗准确子空间投影，也不声称已有创新性证明。

方向仅用目标专家、公开 anchor 和 256 张无标签目标训练图。代理 θβ=θ₀+0.5(θe−θ₀)。在补空间中比较代理与原专家的**图内 token 差异协方差**，取一个广义特征向量；排除 LayerNorm 的恒等空方向。比较图内差异，是因为所有 Key 同加一个常量会被 softmax 消去。

幅度由原专家行中心化分数的 5% RMS 上界解析确定，只算一次；无强度、层数或秩扫描。保留 99.99% 校准输入能量，另用 256 张不重叠训练图确认。未来伙伴在发布编辑包及指纹固定后才载入。该固定候选已经完成：独立 MNIST 99.69% 不变，直接融合 MNIST 99.37→78.80%、SVHN 92.50→54.95%；AGA 后 MNIST 99.32→99.28%、SVHN 91.77→91.89%。代理在这次试验中预测到了直接干扰，未预测到恢复后的效果。14 项计数、原始标签及公式已独立复核。AGA 后 Q/K 差异范数由 21839.43 降至 3.27，但 Attention 分布仍有变化；不能说权重完全还原。该构造停止，不调参。源码固定在 `8d28525`，[完整记录](../results/qk_complement/results.json)。

先测完整 MNIST 独立测试，损失超过 2 个百分点则停止本候选，不调参补救；这个停止规则不是防御成功阈值。通过后测系数 0.5 的 MNIST+SVHN 真实融合及作者原版 AGA，报告两个任务。同条件 AGA 对双方所有 12 层先 Attention 后 MLP。官方测试此前已经观察过，本次不能称盲测或八任务复现。

## 灰度输入的精确补空间

换一个具有准确保持条件的位置：patch embedding 的 RGB 输入。当前 MNIST 预处理把同一灰度值 g 复制成 RGB，再做公开归一化，得到 x=a g−b，其中 a=1/σ、b=μ/σ。取单位向量 v，使 vᵀa=vᵀb=0，C=vvᵀ。对每个卷积核只写入

\[
W'=W+100WC.
\]

因 Cx=0，任何灰度输入的理想 patch 计算不变。它保留的是已知输入任务空间，不是内部压缩。倍率 100 固定一次，未用伙伴选方向、倍率或位置；实际 FP32 保持误差及完整独立准确率都要检查。

这是与上一方案不同的保持机制：不估计中间 PCA 空间，而使用真实输入的线性约束；AGA 原版只恢复 Attention/MLP，未编辑 conv1，因此该补空间项会留下。是否干扰彩色伙伴仍须实测，尚无结果与创新性结论。

两个边界提前写清：线性融合后，灰度任务的输入仍满足 Cx=0，因此不能让 MNIST 融合准确率下降；它只可能干扰伙伴任务。公开恢复 W_clean=W'−(W'−W₀)C 能删除编辑，保留任务平面中的计算。试验同时测这个恢复与未保护对照，不能只展示 AGA 下的伙伴结果便称可靠防御。
