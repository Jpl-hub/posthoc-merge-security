# 任务补空间后处理

目标：已有专家不再微调，保留本任务计算，只在补空间修改参数，使融合后出现干扰。构造与参数选择均不能读取未来伙伴。教师依据是此前保存的录音转写整理；本次未重新取得录音。

## 已有结果

| 构造 | 独立 MNIST | 直接融合 MNIST | 同条件 AGA 后 MNIST |
|---|---:|---:|---:|
| 单层随机补空间 | 99.69 → 99.70 | 99.37 → 8.92 | 99.30 → 99.29 |
| 六处有符号补空间 | 99.69 → 99.68 | 94.00 → 91.91 | 93.23 → 91.01 |

第一行是双任务、系数 0.5；第二行含八个专家、系数 0.2，只评估 MNIST/SVHN。两行不能直接比较。第一行的方向只用目标数据，但从 16 个预设中选择幅度和位置时使用了已知 SVHN 开发融合，不能称未知伙伴验证。第二行不使用伙伴构造，但公开 PCA 清理后达到 93.48%，同条件对照 93.92%，仍不够。

内部压缩曾取得更强的 AGA 干扰，但改变了任务计算，不作为“只改补空间”的成果。历史结果仍留在 Git 和服务器归档，不再保留其运行入口。

## 保持条件

目标校准输入均值为 μ，估计主空间投影为 P，Q=I−P。后处理为

\[
W'=W+RQ,\qquad b'=b-RQ\mu.
\]

输入 x 的局部输出变化是 RQ(x−μ)。只有 x−μ 在 P 内时严格为零；未见图片、分类结果和融合模型均须实测。

[NUFILT](https://arxiv.org/html/2509.21413v2)的子空间对齐有谱间隔、误差与秩条件，其完整方法还优化 LoRA。我们只复用了 SVD，不是完整复现。任务向量的高能量方向、输入 PCA 方向和分类必需方向不能混为一谈。

## AGA 为什么能恢复

对于 PyTorch 每头权重 A，作者求解 AᵀT≈A₀ᵀ，再返回 TᵀA。理想无正则、精确最小二乘给出

\[
A_{\mathrm{rec}}=A_0\Pi_{\mathrm{row}(A)},
\]

即把公开 anchor 投影到发布权重的行空间。大范数扰动并不会原样留下。实际作者代码含 10⁻⁸ 正则与 FP32 转换，不能将理想公式当分类保证。MLP 用余弦配对，恢复机制不同。[论文](https://arxiv.org/html/2606.30360v1)、[固定版本源码](https://github.com/krumpguo/secure-merge-attack/blob/fb61429f5e6f3517102d506697a150ac26abbdea/utils_attack_B32.py)。

下一步只研究一个问题：能否定向改变恢复后的行空间，使 AGA 丢失具体的任务计算，而原发布模型在任务空间内保持原计算？先检查所选计算是否影响分类，再决定是否构造。它与旧随机噪声的区别应是“恢复后删掉哪项任务信息”，不能只是换方向或加大范数；公开 PCA 与替换边界仍须交代。目前没有通过这项判断的新候选。
