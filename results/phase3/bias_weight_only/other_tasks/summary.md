# 防御一：三个任务的无数据构造

噪声方向和幅度均由冻结专家、公开基座及固定分类头的权重确定，不使用真实图片、合成图片或训练更新。MNIST沿用此前结果，本次补齐SVHN和DTD；公式、种子和幅度乘数相同。

TA系数为0.5，数值为完整测试准确率（%）；AGA“仅目标”和“双方”表示处理的专家范围。
