# Attention Key 差异空间：必要条件核验

**结论：停止这一候选，不生成噪声。** 只检查已有缓存的第 1 块第 1 头，不搜索位置、秩、幅度或种子；没有新模型前向和准确率实验。

与旧输入 PCA 不同，这次直接检查 Attention 的保持条件。记图内 Key 均值为 $\bar k$，令 $P_K$ 覆盖 $k_j-\bar k$，$C_K=I-P_K$。若 Query 编辑为 $\delta q=C_KRh$，则

$$
\delta q^{\mathsf T}(k_j-\bar k)=0.
$$

所有 token logits 只增加同一个常数，softmax 不变。融合改变 Key 后可以读出这个方向。但攻击者也能从未修改的 Key 收集投影，清理

$$
Q_a=P_KQ'+C_KQ_0=P_KQ+C_KQ_0,
$$

连同 Query bias，仍把发布与原专家映到同一个状态。它有不同的局部保持条件，**没有解决固定公开投影的恢复漏洞**，不称为新防御。

冻结的 256 张 MNIST 训练缓存中，该头的 Key 差异数值秩为 **64/64**，最小特征值 $4.87\times10^{-9}$，秩阈值 $7.10\times10^{-12}$。因此这个缓存内没有精确非零公共零空间；不推断所有头或真实数据流形的内在维数。

沿用旧诊断的 99.99% 能量保留，得到 42 维主空间和 22 维近似尾部：

| 缓存上下文 | Key 尾部能量占比 | 回填引起的分数变化／原分数 RMS |
|---|---:|---:|
| 独立 MNIST | 0.00923% | 0.00535% |
| 基座至目标的 $\beta=0.5$ 路径 | 0.38651% | 0.02625% |

代理路径确实增加尾部响应，但回填丢弃的专家 Query 更新仍很少影响 Attention 概率。**这些不是分类恢复结果，也不是真实伙伴融合结果**；不据此宣称精确保持或抗恢复。没有足够依据为它生成噪声或继续调秩。
