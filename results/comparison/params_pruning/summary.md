# 固定随机剪枝检查

参考PaRaMS第6节，将48个注意力/MLP权重矩阵按固定种子以10%概率置零，不重缩放。偏置、LayerNorm、嵌入、卷积和最终投影保持。作者仓库未提供剪枝实现，因此这是论文思路的适配检查，不是原表复现。所有发布先固定，再评价10000张MNIST。

| 输入模型 | 剪枝前 | 剪枝后 |
| --- | ---: | ---: |
| 无保护 | 99.69% | 94.35% |
| PaRaMS | 99.69% | 95.60% |
| 防御一 + PaRaMS | 99.69% | 95.60% |
| 防御二 + PaRaMS | 99.57% | 40.73% |

防御二损失5888张、增加4张正确预测，净下降58.84个百分点；这项剪枝破坏了独立能力，停止，不运行融合、AGA或蒸馏，也不改剪枝率或种子重试。防御一剪枝后的预测与PaRaMS剪枝完全一致。

5行完整结果、官方标签与完整索引、逐类及6项配对比较通过独立核对；80个原128批次分数重放最大误差7.63e-6。四份权重、原始分数和冻结源码保留服务器；主方法未替换。

本次结果不否定PaRaMS论文自己的剪枝实验，也不能据此断言所有剪枝方案无效。论文中的剪枝+蒸馏准确率仍接近其无保护对照，不能将剪枝当作已有的抗蒸馏方案。
