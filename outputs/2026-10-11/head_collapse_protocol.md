# 联合头有损重表示：运行前协议

本轮只验证一个 MNIST 构造，层 6–8 沿用目标自身的任务贡献选择。不调整旧噪声，不训练权重，不使用未来伙伴。配置、代码先提交，再生成权重、访问测试集。

## 机制与保持条件

两头输入为 X，原计算为 Aᵢ(X)ZᵢOᵢᵀ + Aⱼ(X)ZⱼOⱼᵀ，Z 是包含偏置的 value 投影。令 C 堆叠两头的增广 value 矩阵，O 拼接输出矩阵。若 Aᵢ=Aⱼ=A，两头等效于 A X̃ Cᵀ Oᵀ；这里 X̃=[X,1]。

从 64 张目标训练输入计算 G=C E[X̃ᵀX̃] Cᵀ。令 O G¹ᐟ²=UΣVᵀ，保留 r=64：

- D=UᵣΣᵣ，B=VᵣᵀG⁺¹ᐟ²C。
- 用共同的 donor Q/K，两个头各持 B/√2、D/√2。

合起来是 A X̃ BᵀDᵀ。标准截断 SVD 最小化声明数值协方差下的 rank-r 线性响应误差，最小平方误差为尾部奇异值平方和。数值零空间以最大特征值的 1e-10 为界；另测真实输入与 FP32 编译误差。

注意力不同则原两头到共同 donor 的差为 (Aⱼ−Aᵢ)ZⱼOⱼᵀ（donor 为 i 时）。完整局部误差还包含压缩误差。对每层 66 对、两个 donor，直接计算实际冻结输入上的总误差，取最小者。这个有限结构选择不使用标签、测试或伙伴；不改变 rank 或重复调强度。

**该推导不保证全模型准确率，也不保证融合干扰。**共享 Q/K 和截断联合算子通常不能唯一恢复原两头；但攻击者无需恢复原权重也可能成功融合。目标只是检验逐头 AGA 是否受影响，以及公开替换和分数恢复能否绕过。

## 文献边界

[AGA](https://arxiv.org/html/2606.30360v1)的原版注意力恢复是参数基线；[SLOA](https://arxiv.org/html/2610.06415v1)说明应当额外考虑组合算子的功能恢复。本轮复用既有最终投影攻击，不声称运行完整 SLOA。

[EMNLP Findings 2025 的头对齐与合并](https://aclanthology.org/2025.findings-emnlp.467/)提供[作者代码](https://github.com/fpcsong/mha2gqa)，使用 Procrustes 及稀疏化。[2026 CAHP](https://arxiv.org/html/2606.19150v1)正文提供[代码](https://github.com/yanivlivert/cahp)，完整流程仍含微调。两者提醒我们头冗余和压缩已有先例；本轮不复现它们、不把截断 SVD 或头合并申称创新。[NUFILT](https://arxiv.org/html/2509.21413v2)的子空间观点作为动机，不能替本轮分类保持提供证明。

## 固定核查

1. 生成三个局部编辑；其余权重逐张量不变。记录全部结构候选误差、选中因子和源码指纹，先保存发布状态再载入其他专家。
2. 目标独立性能、八专家 TA(0.2)与作者原版 AGA；同时测 MNIST、SVHN、DTD、Cars。不是八任务平均。
3. 用公开 anchor 替换选中头，再替换全十二层 Attention。受保护／原专家在这些替换后状态相同，分别说明双方同条件结果，不将一次执行伪称两次新实验。
4. 使用不重叠的 256 训练查询作一次原生分数拟合。DTD/Cars 的 head 约束与 SVHN 的实测成本同时记录。原专家采用相同攻击。
5. 验证实际编辑、SVD 误差、每条真实计数、官方样本标签、全部预测前缀及查询拟合。重文件只留服务器。

失败同样保留。独立损失、直接融合下降、AGA 后差距和最强已测恢复差距并列；没有从信息丢弃本身推出安全结论。
