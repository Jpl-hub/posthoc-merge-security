### 源码核对的新增证据

PaRaMS的`parameter_rearrangement`第60–139行包含对齐选项，`params(...,perm_config=...)`也暴露该参数。它累计A行、B列及偏置内积，`matching`使用`linear_sum_assignment(...,maximize=True)`；AGA只由A行余弦构造代价。两者不是同一实现。

**调用方向已实际核验。** 匹配代价`C_ij`比较第一个模型的神经元i和第二个模型的神经元j，返回的排列作用于第二个模型。官方保护包装函数却先以`(victim, base)`估计排列，再把它作用于victim；在保护模式下这仍保持MLP函数，但不能直接把`obj`改为`matching`就当恢复接口。固定三神经元循环`[1,2,0]`的CPU实验中，内核以`(base, protected)`求解并作用于protected，参数重建误差为0；直接包装调用的重建误差为19.808458，而两者MLP输出均不变。独立NumPy穷举全部6个排列验证唯一最优解。普通两两交换恰好等于逆排列，会掩盖这一问题。

这只是未修改作者内核的方向核验，**不是完整PaRaMS攻击或CLIP准确率复现**，不改既有官方默认防御基线，也未自行补写Attention恢复。源文件SHA256、固定输入、依赖版本、运行时间与结果见[核验记录](../results/phase3/params_matching_check.json)，入口为`python experiments/phase3_params_matching_check.py`（使用已固定的`requirements-params.txt`与CPU PyTorch）。原官方源码保留在`external/PaRaMS`，本脚本逐字节校验，不替换作者求解器。

再核对AGA的实际主入口：固定`main_task_arithmetic_attack_B32.py`使用8任务、TA系数0.2、batch128，每次仅对当前保护专家运行Attention恢复和MLP匹配，再与其余7个原专家融合。现有两任务、系数0.5结果是统一对照协议下的攻击评价，不能称其原论文8任务表已经复现。作者入口引用的`params_mlp_and_invertible`保护权重未随仓库提供，也不能由文件名推断它等于本项目默认对角PaRaMS。

版本、文件Git blob及核对范围见[攻击源码索引](../results/phase3/attack_sources.json)。AGA、PaRaMS、MergeLock复用既有固定提交；ProDistill新增固定提交`c773fcaead79cf25b5654b2e3fe233450da4e387`。其`Vision/main_prodistill.py`对逐块教师特征作MSE，`merge_models.py`冻结教师和基座，仅学习融合系数；默认是逐参数元素系数，不是少量任务标量。校准使用`ValfromTrain`，不能擅自换成测试集。未启动新训练或新攻击评测。

## 融合算法与防御对照

### 新增恢复实验：PaRaMS对角自适应恢复

本轮将原文§6的目标落实为一个固定、可运行的两任务协议，**不是已经取得的CLIP攻击成绩，也不是完整原作者攻击代码复现**。MLP直接调用固定官方匹配内核，以`(anchor, released)`求解并作用于released。Attention针对现有官方默认的对角保护，独立拟合Q、V各行的尺度：

$$a_i=\frac{\langle Q_{r,i},Q_{0,i}\rangle}{\|Q_{r,i}\|^2},\qquad
v_i=\frac{\langle V_{r,i},V_{0,i}\rangle}{\|V_{r,i}\|^2}.$$

随后令`Q←diag(a)Q, K←diag(1/a)K, V←diag(v)V, O←O diag(1/v)`，并相应变换Q/K/V偏置；O偏置、LN和视觉投影不变。这些配对保持Attention函数。原文把恢复Q的拟合矩阵与K的转置尺度相邻叙述，不能不核对逆方向就照搬；这里明确采用保护公式要求的配对逆变换，标为**论文目标的对角适配实现**。不把它扩充为任意可逆矩阵恢复，不借用AGA名称。零行或零／非有限尺度直接停止，不加事后裁剪、正则或重选参数。

固定官方默认保护的小型完整Attention＋QuickGELU MLP计算已通过CPU检查：独立NumPy重建配对矩阵，恢复输出误差2.38×10⁻⁷、参数误差2.98×10⁻⁸。它补上了Attention实现检查，但仍不是CLIP恢复效果。[源码与运行记录](../results/phase3/params_adaptive_check.json)。

真实运行使用新4090协议[params_adaptive.json](../configs/params_adaptive.json)，复用原评价函数和冻结权重：MNIST／SVHN、TA(0.5)、未保护及五项冻结防御参考。先一次性构造并哈希所有恢复编辑，再读图片；两种攻击范围分列。64张小规模控制通过并独立重放后，原编辑不变，评价完整测试集。只新增恢复后的30行，不重跑244行历史表。每行保留原始分数、逐类与配对统计、完整相对间隔变化；独立验证按原128张批上下文重放16个固定位置，分数容差仍为0.0005。O/B、A/B均保留任务预算反例，完整PaRaMS仍为超预算参考。

```bash
python experiments/params_adaptive.py --check
python experiments/params_adaptive.py --pilot
python experiments/params_adaptive.py --verify
python experiments/params_adaptive.py --full
python experiments/params_adaptive.py --verify --full-output
```

CPU检查结果与输出目录均禁止覆盖；服务器首次CPU检查可在未存在对应结果的源副本运行。完整运行必须读取已通过验证的pilot及其冻结编辑，不能因成绩调整方法。新实验结果在独立核验通过前不进入正式主表。

**真实结果已完成。** 本轮源实现先冻结于`a213b8e`，4090上完成小样本30行、480次分数重放，再以相同冻结恢复编辑完成全量30行及480次分数重放，最大分数误差均为0；逐类、配对及全部有符号相对间隔的NumPy复算通过。完整PaRaMS从历史TA的8.92%／9.15%恢复到99.37%／92.50%，与匹配的新无保护恢复控制0改判，提供正对照。Phase1两范围仍为9.80%／6.70%，O/B为78.77%／62.94%，A/B为91.07%／77.46%。这不是新防御，也没有消除O/B、A/B的功能预算反例。

Phase1在此恢复下仍低分，原因范围必须说明：这个攻击也未处理最终LN偏置；NUFILT的真实失效结果仍成立。不能把两种漏改关键位置的恢复流程都失败，解释为任意恢复下鲁棒。新恢复仅覆盖MNIST/SVHN，未外推到其他保护任务。完整表、逐类原始计数、统计及限制见[新增结果](../results/phase3/params_adaptive/tables.md)。历史TA/AGA列来自3090，新列来自4090；微小差异不能作跨硬件因果结论，新配对统计使用同4090的匹配无保护控制。

**代价及归档。** 小规模构造／评价320.58秒，完整评价480.77秒，均零梯度、零防御更新。7次实际MLP匹配调用先于图片；全量不重复构造恢复权重。完整评价492384次图像前向；完整验证480个选定分数实际使用58464次原批上下文图像前向，小规模验证另30720次。独立验证未单独记录精确墙钟，不计作0。原始17份checkpoint及5份冻结发布权重运行后哈希不变；7份恢复权重和两份原始分数已在3090持久数据盘归档并复核，3090未运行GPU任务。4090的27GB历史原始档案没有删除。

**后续补充诊断的明确假设（未运行，不计论文攻击）。** 对任意已发布的CLIP最终LN偏置β和视觉投影P，令`Q=orth(col(P))`、`beta_canon=QQ^T beta`，则`(beta_canon-beta)^T P=0`；理想算术下独立视觉特征对所有输入保持。这可能直接移除Defense1所使用的表示自由度，不需要干净专家、预训练偏置或修改位置的秘密。它是标准投影的安全诊断，不是已有作者攻击复现或新的创新主张。若执行，先冻结三组已有保护任务／伙伴、相同的无保护规范化控制、TA(0.5)与完整逐类验收；不凭矩阵相近直接填恢复准确率。当前仅记录数学风险，没有新增该攻击成绩，也不修补冻结Defense1。

## 统一协议

已完成批次使用相同公开 CLIP ViT-B/32 基座的冻结专家。FP32，关闭 TF32，运行硬件为RTX3090；这些历史条件不追改。后续4090运行需另记录硬件与源码指纹并先重放控制，不静默修改旧协议。分类头独立保留，不参与融合。

设公开基座为 $\theta_0$，发布目标为 $\theta_d$，伙伴为 $\theta_p$，则

\[
\theta_{TA}=\theta_0+0.5[(\theta_d-\theta_0)+(\theta_p-\theta_0)].
\]

两模型下等于算术平均，但复核保留原公式。对齐函数 $A_{\theta_0}$ 使用固定原作者代码，三行分别为

\[
M(\theta_d,\theta_p),\quad
M(A_{\theta_0}(\theta_d),\theta_p),\quad
M(A_{\theta_0}(\theta_d),A_{\theta_0}(\theta_p)).
\]

英文表列名采用 **No attack / AGA (protected expert) / AGA (all experts)**。两种作用范围不能合并或取较低准确率。TIES 与 TA 分表；TIES 系数 1.0 乘的是同号非零均值，不能与 TA 的 0.5 向量和混称为相同系数。

AGA 的 Attention 逐头独立求解使用作者 float64 与 $10^{-8}I$ 正则，结果写回 FP32；MLP 使用作者余弦代价和匈牙利匹配。当前直接复用已固定同一源码生成、有哈希和独立核验的攻击权重，没有改成整层拟合、低精度求解或重新调正则。源码同时校验原始字节和统一换行后的文本哈希。

TIES 直接执行固定文件中未修改的纯函数；AST 仅排除 T5 加载、绘图等无关导入。全模型浮点张量按键排序后统一展平，包含偏置与 LayerNorm，逐任务保留前 20%，不逐层设阈值，不因防御强度改变裁剪规则。用一个固定小矩阵的独立 NumPy 实现检查裁剪、符号与聚合，并重建完整模型重放图片；这不等于第二套完整规模 TIES 实现。

## 安全结论的限制

原版 AGA 不修改最终 LayerNorm 偏置或视觉投影，Phase 1 效果包含明确的攻击覆盖缺口。不能由此宣称对任意恢复攻击鲁棒。已知位置的预训练参数替换是额外、带位置知识的诊断，不是原任务向量恢复，也不叫原版 AGA。此次主实验不围绕它调防御。

O/B 越界见证、A/B 的有限确认、PaRaMS 超预算和类别集中损失全部保留。无数据 AGA、数据辅助融合、蒸馏训练的攻击者能力分别列明，不能在一张表中省略权限差别并声称统一安全保证。

## NUFILT 恢复链的先决检查

使用已有固定提交 `4cd298fb7ea22bd4bcd343748fb4b8e3f9815324`，补查 `nufilt.py`、`filter_lora.py`、默认 YAML 和[论文实验与超参数表](https://arxiv.org/html/2509.21413v2)。源码与[只读 CPU 检查](../experiments/phase3_nufilt_check.py)的指纹、数值保存在 `results/phase3/nufilt_source_check.json`。这是初始源码检查，不是完整 NUFILT 复现；后续本批对应适配实验见文末。

官方默认只选择 Attention 与 MLP `fc1` 的线性权重，零空间秩128、LoRA秩64、任务方向秩8、Adam学习率0.001、50步。该求解使用权重投影目标，不需要图片，也不重新训练输入专家；若作为攻击后的融合链，梯度次数和代价应归入攻击者。

当前 checkpoint 将 Q/K/V 合在 `in_proj_weight`，MLP 第一层叫 `c_fc`；官方 HF CLIP 使用独立 Q/K/V 和 `fc1`。直接按官方模块名筛选实测只命中12个 O 矩阵，而非其预期60个矩阵。未选择的偏置、LN、fc2 等保持初始化基座状态，不能擅自补平均；视觉投影和分类头也必须核对。这些规则直接涉及 Phase 1 的编辑位置，不能忽略。

设先前融合增量为 $M$、当前任务增量为 $T$、先前右奇异方向为 $V_p$，源码最终矩阵使用

\[
M'=M+TG,\quad G=I-V_pV_p^\top+BA,\qquad
L=\|(T-M')V_t\|_F^2+\|(M-M')V_p\|_F^2.
\]

这里 $V_t$ 取8维、$V_p$ 取128维；$A,B$ 是融合端门控变量。约束的是参数作用探针，不保证完整分类功能。模块的偏置及其他跳过参数没有出现在该求解或最终权重写回中。

小矩阵检查确认官方投影损失与最终合并矩阵目标一致。另一个检查发现非对称门控下，临时 gate 的 forward 与 `merge_to_base` 的线性方向不完全相同；官方优化用后者的显式矩阵目标，因此此现象**不等于最终算法无效**，但不能用临时 forward 替代最终合并后评价。

三个 Phase 1 发布包及对应 AGA 编辑包已逐一核对：均只有 `ln_post.bias`，与 NUFILT 读取的任务权重集合没有交集。由其实际代码的数据依赖可得：在同一基座、种子、任务顺序及相同所选权重下，原版流程的最终合并参数相同，保护偏置不进入计算。**这是参数覆盖性的条件结论，不是已经测得的 NUFILT 准确率或恢复成功率。**还必须验证无保护 NUFILT 融合本身能保持多少任务能力，才能评价实际恢复价值。

本批实现前登记的对应检查为：QKV拆分／MLP映射的等价性检查、偏置与读出的处理核对、原作者首任务初始化规则、两个固定任务顺序的登记，以及最终融合权重的独立复核。不能直接给漏层适配贴上“官方 NUFILT”标签，也不能预设它比 TIES 更强。本批随后按固定作者内核完成了对应验证，实际范围和结果见文末；未执行的任务组合仍不填准确率。

### 不能混同的三种恢复

MergeLock 使用伙伴作为参照，以同一正交矩阵旋转 Q/K 并匹配偏置；AGA 使用公开预训练锚点的逐头最小二乘，约束与参照都不同。前者的抗对齐结果不能代替后者验证。已下载并目视核对 MergeLock PDF 第9页：V/O 式 (11) 同样将两个范数项相邻排版，没有加号；不能仅将其当成网页转换错误而自行替换目标。PDF SHA-256 为 `8d1a63f2cd6a9945628e3af7cfcfec1f4dc5fe3f24650c02b009202fefde6cbf`，原文公式歧义与缺少官方实现一并保留。

MergeGuard 的 Unmask 在两专家 TA 下可直接化简：

\[
[\theta_0+\lambda((\theta_d-\theta_0)+(\theta_p-\theta_0))]-\lambda\theta_d
=(1-2\lambda)\theta_0+\lambda\theta_p.
\]

它完全消去了保护专家项；获得一定准确率不自动表示恢复了该专家知识。论文使用系数0.3，本项目不能临时改系数后仍称相同设置。GradErase 需要估计扰动与梯度再训练，属于更强的数据／计算权限。

MergeBarrier 明确把修改层替换回基座作为结构防御的评价操作。这为补充诊断提供文献依据，但该操作仍具有位置知识，且不是原作者 AGA。不能把术语混淆成统一的“恢复攻击”。

NUFILT 还存在必须保留的首任务细节：前一任务增量为零时，官方仍对该零矩阵做 SVD 并使用返回的前128个右奇异方向；首任务不运行 LoRA 优化。不能自行将它改成直接接收完整首任务权重。任务顺序、所用 SVD 驱动及模块遍历顺序也影响可复现性，完整适配前须登记。

## NUFILT 首批固定适配验证

在完整恢复分数之前，只新增同一对 MNIST/SVHN 的无保护、Phase 1 MNIST、A/B；O/B 已在 TA/TIES 中作为越界参考，NUFILT 首批不扩展所有历史方法。两种任务顺序全部保留，不选最优顺序；每个顺序均运行无攻击、AGA 仅保护专家、AGA 全部专家。

直接调用固定作者 FilterLoRA 的 SVD、投影损失与最终矩阵函数。仅做 native packed QKV 与 c_fc 的显式权重映射，模块顺序 k/v/q/out/fc1 对照 Transformers v4.52.4 的 [CLIP 实现](https://github.com/huggingface/transformers/blob/v4.52.4/src/transformers/models/clip/modeling_clip.py)；不声称复现完整 FusionBench 应用或论文多任务表。所有未选择参数严格保留公开基座，包括偏置、LN、fc2 和视觉投影。

保留官方首任务零增量 SVD／不优化规则；后续任务使用原默认50步 Adam、0.001学习率与64/128/8三个秩，不因本项目成绩改值。优化对象仅为融合门控，不更新任何专家或防御；预注册12次实际两任务融合、合计600次全局反传。Phase 1 的所选输入逐个精确断言相同后，复用对应无保护合并权重和分数，并明确标注这种复用。

先做每任务64张的端到端检查，独立重建完整有限矩阵并重放分数，确认后用完全相同的已保存合并权重评价完整测试集，不再重新求解。原始大权重、门控与分数只在服务器。原分数阈值0.0005不变；所有结果与匹配的同顺序、同攻击范围无保护 NUFILT 控制配对。

## 数值重放的条件

DTD Phase 1 的首轮16张重放误差0.000715超过原0.0005阈值，保留失败日志。原完整评价使用128张批，改变为16张会改变矩阵计算形状。后续验证仍选择原来预定的16张，连同它们原始批次上下文一起计算，阈值、分数、标签及保护参数不变；额外前向图片数单独记录。这只是验证计算条件的修正，不是防御重调或放宽验收。若相同条件仍不通过，结果不能进入正式表。

## 冻结方法的任务预算反例

固定512张 MNIST 训练图的只读审计中，O/B、A/B 各有1张超过0.5。最大见证都是训练索引31374，真实标签7，教师预测7；完整模型按原128张批上下文重放，分数误差均为0。原教师7/9分数间隔0.020336，O/B间隔变为0.129522（相对变化+5.369068，仍预测7），A/B变为−0.791487（相对变化−39.920184，预测9）。

## 本批已验证结论

正式 TA/TIES/AGA 包含4个预登记任务组合、208行；NUFILT 包含 MNIST/SVHN 两个顺序、三种攻击范围、无保护／Phase 1／A/B，共36行。244行全部完成官方标签、逐类与配对 NumPy 复算及完整模型抽样重放，合计3904次分数重放。NUFILT 全量重放最大分数误差0.00002861，小于原0.0005阈值。完整表、CSV、SVD审计、模型与源码指纹见 [`results/phase3`](../results/phase3/tables.md)。

- **恢复效果取决于融合方法。** MNIST/SVHN 的 AGA 仅处理保护专家时，TIES 下 O/B 为57.13%／50.75%、A/B 为65.76%／66.21%（目标／伙伴）。它没有比 TA 提供更强恢复。两者均有任务预算反例，不能作为严格可行性比较的胜者。
- **NUFILT 下 Phase 1 失效。** 两种顺序及三个作用范围中，其所选输入权重与对应无保护控制精确相同，最终合并模型相同、配对预测差异为0；实测 MNIST 99.07%–99.43%、SVHN 93.75%–95.35%。这不是仅凭参数范数作出的结论。未修改防御，未进行专家训练；常规融合的跳过规则已经消除了关键偏置的影响。
- **A/B 的保护高度依赖融合算子。** 相同 NUFILT 设置下 MNIST 为98.86%–99.33%，距匹配无保护控制仅0.06–0.31个百分点；伙伴为93.72%–95.38%。未按结果选择顺序、种子、秩或步数。残余小幅差异不叫“完全恢复”；原强保护效果没有跨到该算法。
- **预算结论已更正。** 原参数距离 O/B 0.29904、A/B 0.364139 在0.5内，但完整任务保持均有反例。此前有限确认与真实融合效果继续保留，不能再宣称这两点满足全任务0.5上界。没有通过本阶段结果修复任何权重。

NUFILT 是原作者内核加显式 native 权重适配，不是全套 FusionBench 或论文多任务表的复现。Phase 1 分数复用有逐权重相同断言，不冒称重复运行了另一套优化。当前只完整测量保护 MNIST 的 NUFILT 结果；DTD/SVHN 的偏置覆盖性已由源码检查，但未填其绝对恢复成绩。两种顺序不是多随机种子均值；这里只用固定 seed42。O/B 未纳入本批 NUFILT，不从 A/B 外推其结果。

**代价。** 四组主评价累计约46.1分钟（不含单列的独立重放成本）；NUFILT 构造／小样本验证约10.1分钟，全量评价／重放约8.7分钟。NUFILT 共12个不同合并模型、600次融合门控全局反传；专家与防御更新均为0，无图像参与门控求解。运行仅用 RTX3090，分段墙钟时间不是隔离的算法加速基准。

### ProDistill的实际优化权限：先核代数，再作只读参数统计

原文§4.1和附录C.1明确采用逐元素系数；固定`MergedModel.get_merged_model`也没有将alpha限制为任务标量、凸组合或区间。对每个块参数j，`w_j=w0_j+sum_i alpha_ij tau_ij`。在实数代数下，只要`sum_i tau_ij^2>0`，这一坐标就可取任意值；系数到合并权重映射的秩正是非零坐标数。普通SGD诱导的权重更新含对角因子`sum_i tau_ij^2`，但作者实际用Adam，不能据此声称两种训练轨迹完全相同。这个可达集合结论也不保证有限迭代、浮点数或分类恢复。

因此“专家冻结、只优化融合系数”并不等于低维或无训练攻击。逐元素相乘甚至可以离开原任务矩阵SVD的左右子空间（例如全1的秩1矩阵与单位阵作逐元素乘法后秩为2）。这不是新方法或原创性主张，原文已说明更高表达能力；它用于精确披露本项目攻击权限，以及解释SVD探针对防御构造的约束不能自动约束攻击者。

唯一只读统计：使用已冻结九组MNIST/SVHN端点，逐块计数此参数映射的支持秩、系数维度及对角尺度范围；再比较已保存U与O/B、A/B合并权重的前11块是否逐位一致。零图片、零梯度、不重跑训练、不修改保护。它不从准确率挑选下一防御，也不把参数可达性当实际攻击成功；实际成功仍以双任务分数和独立核验为准。


只读核验已完成：九组的12块均为85,054,464个权重坐标，支持秩同为85,054,464（100%）；累计170,108,928个逐元素系数，按块训练而非同时全部驻留。对应对角尺度最小1.55e−16、最大0.15946，故代数满可达并不代表良好数值条件或任意目标都能在100epochs实现。O/B、A/B与各自控制的末块以外参数逐位相同，差异确实集中于最后块；没有读取新图片或重跑训练。此项CPU27.47秒，0梯度、0新权重，[原始统计](../results/phase3/prodistill/capacity_audit.json)。这明确了攻击权限和机制范围，不能把标准逐元素参数化包装为新攻击或原创防御结论。
