# 最后一层 CLS Query：先检查清理代价

这是一项必要条件诊断，不是新防御。只检查 block 11 的 Query；不改 Key、Value、MLP，不生成噪声或保护权重。不按伙伴效果换层、换头、换秩。

与已关闭的 block 0/head 0 不同，位置由分类结构确定：最后一层之后没有跨 token 运算，分类只读取 CLS。因此，保持最后一层 CLS 的 Query 就足以保持该层的 CLS Attention；patch Query 的变化不会再传到分类输出。实际 `open_clip/model.py` 指纹为 `cd1721053da93a0c85a2d9390d575910d5482bca0c092980e4469c760eb58029`，末层之后的 MLP、LayerNorm 都按 token 运算，407 行只取 CLS。

设末层 LN1 的 CLS 输入为 $x=\mu+u+e$，$Pu=u$，$C=I-P$，$Ce=e$。允许的 Query 修改满足

$$
Q'=Q+E,\quad EP=0,\quad b'_Q=b_Q-E\mu.
$$

若所有原任务 CLS 都有 $e=0$，则原任务分类计算精确保留；真实 PCA 只给近似关系，误差为 $Ee$，必须另测校准外输入。每个头的 CLS 分数变化为

$$
\delta s_j=\frac{(Ee)^\top(k_j-\bar k)}{\sqrt{64}}.
$$

这比要求所有 token 的输入都落在同一空间弱，但**没有改变公开清理等式**：

$$
Q_c=Q'P+Q_0C,\qquad
b_c=b'_Q+(Q'-Q_0)C\mu.
$$

保护与未保护模型仍映到同一状态。清理丢掉的有用计算只可能来自原专家更新 $\tau_Q=Q-Q_0$：融合中 CLS 分数变化涉及

$$
-\frac{\lambda[\tau_Q C(x_m-\mu)]^\top(k_{m,j}-\bar k_m)}{\sqrt{64}}.
$$

如果融合改变上游 CLS，而这项原专家 Query 更新原本帮助 MNIST 进行 Attention 路由，回填可能有代价；其存在和分类价值尚未验证。不能把补空间响应大、参数变化大或末层重要直接当作代价。

只做一次冻结诊断：1024 张 MNIST 训练输入确定投影，另一份不重叠的 1024 张训练输入重估公开投影，512 张确认。沿用已有 99.99% 能量规则，并保留 LN 仿射约束法向量，避免把全任务通用空方向当成 MNIST 特性。位置、规则和两份回填在读取 DTD 前冻结。PCA 不使用标签；训练确认和测试只用于测量。

先测公开回填原专家的独立性能，再测 MNIST＋DTD 的两项融合性能。重用已核验且模型指纹相同的原始基线预测；新增结果保存逐样本预测并独立复核。DTD 独立性能同时列出。若两份公开回填仍保留 MNIST 融合能力，关闭这个区域，不构造噪声，不运行 AGA，不追加扫描。即使回填有代价，也只是下一步防御的必要条件，不能称抗恢复成功。

## 实测：这个区域也停止

| 指标 | 未回填 | 原投影回填 | 独立公开投影回填 |
|---|---:|---:|---:|
| MNIST 独立 | 9969/10000（99.69%） | 9969/10000 | 9969/10000 |
| MNIST 融合 | 9945/10000（99.45%） | 9945/10000 | 9945/10000 |
| DTD 独立 | 1493/1880（79.41%） | 同一伙伴，未修改 | 同一伙伴，未修改 |
| DTD 融合 | 1303/1880（69.31%） | 1302/1880（69.26%） | 1302/1880（69.26%） |

两份回填的 MNIST 独立和融合预测都逐样本不变；DTD 各只改变 1 张预测。两份投影保留 638、641 个方向（含 LN 法向量），删掉约 6.27%、5.75% 的 Query 任务更新能量。能量变化不能代替分类代价。

这里前 16 个 PCA 方向只覆盖约 92% 的 CLS 方差，99.99% 需要 637／640 个方向；这不是“分类需要 637 维”的证明，也不能据此否定老师的低维思路。它说明不能把 16 维假设直接当成这个实际算子的精确线性零空间。

NumPy 独立谱分解与回填公式、原始测试标签、10 行计数、模型指纹及 1280 张重新前向核对通过。基线 4 行复用已有核验记录，新增完整评估 6 行；权重片段、统计和原始预测均只存服务器。见[计数](../results/final_query_completion/results.json)、[独立核验](../results/final_query_completion/independent_validation.json)。

**没有突破。** 这是原专家的回填代价诊断，没有保护模型、AGA 结果或新的抗恢复证据。最后 CLS Query 虽比首层全 token 条件宽松，回填仍保留受保护任务的融合能力；不把换位置当新方法，不继续加噪声。
