# 共享前缀参数的有限分类博弈

## 可实现环境

原专家$\theta_e$、公开基座$\theta_0$和O/B发布点全部冻结。参考模型为$\theta_c=(\theta_e+\theta_0)/2$。只在第10块MLP输出矩阵$D$上引入共享环境参数

$$E(S)=\|D_e\|_F U S V,\qquad S\in\mathbb R^{32\times32},\quad\|S\|_F\le0.5.$$

$U,V$沿用源任务向量$D_e-D_0$中已冻结、按源功能响应选取的奇异基，不重选层、秩或模式。矩阵$E$对全部图片、全部token相同。若该层输入激活为$Z_i$，则最后块输入变化**精确**为

$$H_i(S)=H_{c,i}+\|D_e\|_F (T_iS^\top)U^\top,\qquad T_i=Z_iV^\top.$$

这不是逐样本表示球或接口见证的投影。取假想伙伴$\theta_p=\theta_0+2E$，真实TA(0.5)参数恰为$\theta_c+E$；发布O/B变化$\delta$后为$\theta_c+E+\delta/2$。因此该环境族有同一参数模型的明确实现，而不只是任意隐藏向量。这里没有把假想伙伴称为已训练专家，也没有读取任何真实伙伴信息。

未知伙伴一般还会改变其他前缀、Attention、MLP、LayerNorm及读出。它是否接近这一个子族，以及这些未建模变化的方向和幅度，仍无覆盖保证。即使本博弈有效，也必须另行进行冻结后的真实TA／AGA。

## 内层任务约束与类别对手

共同环境必须同时满足两组完整有限约束：

$$\max_{i,k,\pm}R_{ik}(\theta_e+E,\theta_e)\le0.5,\qquad
\max_{i,k,\pm}R_{ik}(\theta_c+E,\theta_c)\le0.5.$$

第一组沿用4,608张自然训练图片和5,120个D/B任务奇异探针，共9,728个输入；第二组检查参考环境中固定512张目标训练图片。自然预测均须保持。原专家checkpoint没有更新；$S$是诊断中的环境变量，不是新发布权重。环境归一化矩阵上限0.5，不放宽发布参数距离或任务保持的原双0.5预算。

对参考教师类别$y_i$和固定原间隔$g_i>0$，保护联合模型的有限间隔为

$$m_i(S)=\frac{s_{y_i}(H_i(S);p_c+\delta/2)-\max_{k\ne y_i}s_k(H_i(S);p_c+\delta/2)}{g_i}.$$

内层环境寻求恢复正确排序，类别对手强调恢复最困难的类别：

$$\min_S\max_{\pi\in\Delta_C}\left[\sum_c\pi_cL_c(S)-\tau_c\mathrm{KL}(\pi\|\mathrm{Unif})\right],$$
$$L_c=\operatorname{mean}_{y_i=c}\tau_m\log(1+e^{-m_i/\tau_m}).$$

类别内层有解析解$\pi_c\propto e^{L_c/\tau_c}$。本轮固定$\tau_m=0.25,\tau_c=0.1$，不扫描温度。完整Attention、QuickGELU、末LayerNorm与特征归一化均进入有限目标。损失改善不能代替分类效果；另外报告每类实际恢复和当前改判。

## 冻结的唯一求解路径

从$S=0$开始，最多12次共享参数提议。固定40个源低间隔上下文、每类1个参考上下文，加当前各类最坏约束见证，构造局部任务Jacobian。最小范数法向步减少已有保持残差，切向步下降类别极大损失。局部模型只产生提议，所有接受点均须通过全部10,240个输入的实际有限约束。

信赖域初始0.025、上限0.05、下限$5\times10^{-5}$。只有实际目标改善、实际／预测改善比至少0.1、活动约束线性预测与完整非线性约束均通过才接受；拒绝则半径减半。既定提议次数、预算、秩和输入不增加，不以修复后的测试结果重启。

解析共享梯度先与完整512输入的直接Autograd反向核对；每个提议再核对实际有限差分。独立NumPy重算所有提议、全部源与参考响应、类别对手及逐类预测、活动方向导数和接受决策。保存源码冻结、系数、原始分数、拒绝见证、成本和指纹。

本路线的源内信号预设为：至少恢复16张原O/B参考改判，涉及至少3类，同时所有任务约束满足。它仅决定是否值得设计外层发布博弈，不是防御效果，也不是其他方法的必要条件。无信号就关闭本固定协议，不继续扩大次数或扫描参数。若有可信信号，下一外层才在原双预算内直接优化环境最坏的**联合分类失效**与参数距离，并履行冻结、独立确认、真实TA／AGA的顺序。

```bash
python experiments/shared_environment_game.py --protocol configs/shared_environment_game.json
python experiments/verify_shared_environment_game.py --protocol configs/shared_environment_game.json
```

## 与已有工作的区别

[TSV（CVPR 2025）](https://arxiv.org/html/2412.00081v2)已经提出逐矩阵任务奇异结构与白化；[ESM（CVPR 2026）](https://arxiv.org/html/2602.20208v1)已研究任务更新引起的功能偏移子空间。奇异分解、投影和子空间本身不是这里的创新。[PaRaMS](https://arxiv.org/html/2503.07661v1)已采用参数距离及函数对称性；本环境没有排列或配对缩放。[AGA／ARF](https://arxiv.org/html/2606.30360v1)分别是锚点恢复攻击和需要微调的排斥防御，不等同于本轮后处理。

本轮待验证的实际内容是：一个源端定义、由共同参数实现、受有限任务约束的环境对手，能否改变O/B的联合类别排序。标准极大极小与信赖域不构成新颖性证明。本轮没有宣称新增保护效果或对未知伙伴的通用保证。
