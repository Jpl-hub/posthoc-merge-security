# 三层完整替换与功能恢复

问题：Cars 9–11 层此前仅替换 Attention／MLP，保留了原专家的 LayerNorm。现在把这项遗漏纳入同一固定恢复检查，判断恢复是否依赖残留的归一化参数。不是新防御实验。

数学边界：LayerNorm 的可逆仿射重表示已有公开消去公式，见[此前推导与实测](../2026-10-10/subspace_compensation_mnist_canonical_fc/summary.md)。在相同 epsilon、公开 gamma 非零时，令 `Wc = W diag(gamma/gamma0)`、`bc = b + W beta - Wc beta0`，便能将 LayerNorm 仿射项改为公开值，同时保留后续线性计算。重新排列这项耦合不能自动增加恢复成本。本轮不重复该对称性实验，检查的是直接删除实际任务特有参数的代价。

只用原 Cars 教师、公开预训练模型和历史冻结的 256 张 Cars 训练图。区域沿用此前目标任务选择的 9–11 层，不使用未来伙伴选择或构造区域。三个完整 residual block 的 Attention、MLP、两组 LayerNorm 全部换成公开参数；其余张量不改。然后复用[已有恢复代码](../../experiments/block_restore_gate.py)，依前向顺序各做一次公开 MLP 神经元基上的下投影及 bias 闭式拟合，固定 ridge 比例 1e-4，不调参数。

教师响应为三个完整 block 输出，共 29,491,200 个标量；这属于较强白盒访问，不是 256 个类别查询或微调。恢复算法读取当前学生的实际 MLP 输入，以“教师完整 block 输出减当前 Attention 后残差”为目标。归一化、Attention、MLP 上投影始终保留公开值。拟合不读取真值标签；区域历史选择用过目标训练标签。

评价采用固定八专家 TA(0.2)，在 Cars、MNIST、SVHN、DTD 官方完整测试上记录原／替换／恢复模型。十次新完整评价，五条已核验的原模型记录复用；不复用旧支持的替换结果。额外攻击不混入作者 AGA，缺 EuroSAT 原划分时不报八任务均值。

运行前冻结源码、配置、样本索引及父结果指纹。预测和恢复张量只留服务器。独立进程用 Cholesky 重算三次拟合，检查全部十五行计数、配对变化和每行 128 图预测前缀。默认旧配置继续保持原 Attention／MLP 支持；新增配置明确 `reset_component=block`。

解释限制：完整替换把任何仅修改这三块、架构及其余参数不变的发布统一映射到固定状态，所以它的实测融合准确率可构成该支持族的恢复下限。功能拟合的迁移还要求发布模型保留攻击可见 block 响应；仅独立分类准确率相近不能推出这一条件。无受保护权重，因此不能把恢复控制写成保护成功或所有机制的不可能结论。无论结果如何，不据此扩大强度、秩或层数扫描。
