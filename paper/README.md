# NBP manuscript

当前为英文初稿，方法名暂定 Nullspace Bias Perturbation。名称检索与先行工作核对尚未形成排他性结论，不使用“首次”表述。原始工程中的 Defense1 标识保持不变，文稿统一显示为 NBP。

## 文件

- `main.tex` 组织正文，`sec/` 保存各节。
- `cvpr.sty` 和 `ieeenat_fullname.bst` 直接来自用户提供的 CVPR2027 官方模板，未修改。
- `tables/` 的 Markdown 与 TeX 由同一份已核验结果生成。`python paper/make_tables.py` 只导出文稿表格，不运行模型。
- `fig/mechanism.tex` 是可编辑矢量结构图，没有模拟实验数据。
- `python paper/make_figures.py` 从42组真实权重分析记录生成 `fig/readout_bound.pdf`，不运行模型。实际两专家和八专家各有5/7个任务通过常数分类的充分条件；SUN397、Cars未通过，不能把充分条件写成所有任务的必要条件。
- `main.bib` 从原论文的 arXiv、PMLR 元数据取得，引用版本仍需逐项检查并尽可能换为正式出版条目。

## 当前范围

正文只写 NBP。已有七个保护任务的两专家结果，以及三任务的固定公开 B 替换和 ProDistill 结果。八专家大表、缺少的融合方法、其他可复现防御基线及机制消融需要继续补齐。尚未完成的结果不会填入数字。

SUN397/MNIST 的 TIES、DARE+TA 对比已完成27条完整结果和432个原批次分数重放，重放误差0，已进入表格。八专家扩展的四个新保护方向正在17897完整评价，计划168条完整结果。所需缺失模型和数据已从旧21516按清单迁入，33份冻结权重哈希通过；历史失败权重未整批复制。

MNIST机制消融已按 `results/phase3/bias_weight_only/ablation_protocol.json` 固定：主方法相对幅度0.125、0.25、0.5、1、2，另含同范数随机零空间方向和普通随机方向；零幅度复用无保护对照。共六个新控制、八个条件，每阶段40条完整结果。控制参数已在图像评价前保存并记录哈希，GPU评价等八专家作业成功后串行开始，当前没有结果可填。
