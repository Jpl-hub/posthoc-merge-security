# 局部联合有损改写：一次机制检验

这是候选检验，不是已获得的新防御。已有 PCA、模型压缩、响应拟合和功能迁移工作覆盖各个工具；不以它们的组合本身宣称创新。只构造一个 MNIST 候选，层 6—8 沿用目标专家自身的旧分析，未证明该区域不可替换。

Attention 每个 head 的原始 value 为 Z=X Vᵀ+b。由目标校准响应的未中心化二阶矩取 32/64 维正交投影 P，编译为 V'=PV、b'=Pb、O'=OP。Q/K 不变。对于同一输入及 attention map A，有 O'A Z'=OP A Z，误差为 O(I−P)A Z；投影与 token 上的 A 交换。不同输入产生不同 A，不能据校准能量推导测试准确率。

MLP 原 affine 预激活 z=Wx+b、输出 Vg(z)+d。用目标校准 g(z) 的未中心化二阶矩取 E∈R^(3072×768)，EᵀE=I。新输入权重为 Eᵀ[W,b]，仅占标准 3072 宽结构的前 768 行；其余神经元为零。一般 g(Eᵀz)≠Eᵀg(z)，因此这不是可精确撤销的线性换基。单独的秩亏只说明参数映射非单射，不能证明攻击者不能功能重建。

按层前向顺序，用当前候选的真实输入计算 φ=g(Eᵀz_current)，目标为原专家完整 block 输出减去候选的 post-Attention 残差。每层一次闭式 ridge 更新，复用既有求解器，ρ=10⁻⁴。三个拟合均明确属于依赖校准的后处理，不称作数据无关变换。它尝试把丢失的 Attention 响应迁移到 MLP，同时换掉 MLP 非线性坐标；校准误差小不保证泛化，也不保证融合破坏。

预期可证伪：若任务响应可由较窄表示补偿，且公开补全不能廉价找回兼容的计算，后续真实融合可能出现性能与恢复成本的分离。若原任务损失明显、公开替换仍便宜、或功能迁移同样成功，就否定本次固定构造。不能把已有压缩的收益当作安全收益。

先检查三个模型的独立性能：原专家、实际编译发布权重、知道 E/P 的 oracle 补全。补全公式为 W_r=E W_code+(I−EEᵀ)W₀、V_r=V_code Eᵀ+V₀(I−EEᵀ)；Attention 用投影保留发布响应、补入公开补空间。MLP frame 不假设公开可识别，故这项攻击有额外 oracle 信息。另核对完整公开支持替换使原始与发布模型逐 tensor 完全相同。

旧匹配对照给出支持替换后 MNIST 独立 98.73%、融合 87.23%，原始融合 94.00%。这是仅修改 V/O/MLP 6—8 的条件性恢复下限，不是不可逆机制的成功证据，更不是整体方法不可能的定理。Attention 公开可逆的符号翻转已经排除，不进入实验。

构造只读目标专家、公开预训练模型及目标训练校准图像。前 256 个旧 profile selection 样本无标签拟合；2048 个 profile confirmation 与其不交，但已经用于旧诊断。测试集也曾被观察，不称新未见研究数据。一次固定秩、层和 ridge，无搜索；先保存权重并复核，性能合理时另冻结真实八专家融合及攻击阶段。
