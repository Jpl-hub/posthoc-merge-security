# 防御二：无数据参数修改

目标是在不读取真实图片、不重新训练原专家的条件下，修改发布参数，保持独立分类能力，并降低融合后的受保护任务准确率。

目前尝试的核心流程是：

1. 对原专家与公开基座的MLP权重差做SVD，取32个任务方向，构造这些方向上的合成输入。
2. 在任务方向的补空间大幅修改A。A可以在优化中调整，原专家保持冻结。
3. 根据新A产生的激活输出求B，使A、B共同补回原模型在固定任务输入上的响应。
4. 用合成图比较原模型与发布副本的完整分类输出，寻找差异并联合调整。最后只发布修改后的A、B权重。

B的补偿针对激活后的输出，而非只保持两个线性矩阵的乘积。具体公式、参数范围和源码见[构造定义](response_compensation_protocol.json)。

完整MNIST的结果如下，原专家准确率均为99.69%。

| 构造 | 合成视图预测保持 | 修改后独立准确率 |
|---|---:|---:|
| 固定输入、逐层重构 | 800/800 | 45.17% |
| 主动生成输入、逐层重构 | 2851/3200 | 71.65% |
| 固定A、联合任务响应拟合 | 563/3200 | 9.74% |
| 完整源目标求解对照 | 385/800 | 9.82% |
| A/B同步修改、保持线性乘积 | 906/3200 | 15.08% |
| A可调、B匹配非线性任务响应 | 2017/3200 | 9.63% |
| 完整前缀与局部任务响应补偿 | 64/64 | 9.14% |

这些构造的输入数量和目标不同，表中呈现的是探索过程，不是等计算量消融。上述点均未保住独立能力，没有继续做融合或AGA评价。

最新构造在12层固定任务方向上的输出误差约百万分之一，但真实图片几乎全部被判为“6”。这说明当前任务探针没有约束住完整分类功能；同时合成输入仍有1183/3200个预测未保持。接下来集中解决无数据输入与完整功能保持之间的差距。

新完成的输入对照中，类别约束组和加入论文先验组各32张合成图，均在五个固定平移下满足全部指定伪类别。这是合成图检查，不是真实任务准确率。原模型前六层的实际CLS输入仅约1.7%至6.5%的能量落在当前SVD探针平面；只蒸馏这个平面无法代表完整输入。在完整输入附近，SVD方向测到的任务功能差异能量分别是随机方向的1.93倍和2.44倍。因此当前把完整输入用于功能保持，把SVD用于局部任务响应。[输入对照及测量](source_prior_result.json)。

新的固定构造已完成：逐层使用发布副本的实际输入，联合调整A，并条件求解B，补回原教师完整块输出及其局部任务响应。64/64个源预测保持，但完整MNIST只有9.14%，没有继续融合或AGA。原专家不更新，真实构造图为0；唯一模型与原始分数已留档。具体流程和范围见[构造定义](local_prefix_protocol.json)，[完整结果](local_prefix_result.json)。按用户要求暂停，原始分数独立复核留待下一次继续。
