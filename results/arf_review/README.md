# AGA / ARF 核对

[AGA §2.2](https://arxiv.org/html/2606.30360v1#S2.SS2)的防御主指标是**受保护任务**的融合准确率下降，同时保持独立效用。伙伴下降应另报，不能代替这个指标。

[ARF §5.1–5.2](https://arxiv.org/html/2606.30360v1#S5.SS1)是 Attention 排斥锚点微调，再施加可逆参数保护。它是需要训练的防御基线，不是攻击，也不是本项目要求的免额外微调方法。新后处理方法本身可以直接评测，不以先叠加 PaRaMS 为前提。

论文 Table 6 中 MNIST 未保护融合为 97.55%，ARF 后为 10.44%，AGA 后为 29.12%；Table 8 独立 MNIST 为 99.65% → 99.06%。**这是作者报告，未在本项目复现，不能与双专家 TA(0.5) 直接排名。**

[固定源码记录](source_audit.json)核对了作者仓库 `fb61429f5e6f3517102d506697a150ac26abbdea` 的 20 份 Python 文件；未找到 ARF 训练入口，现有 checkpoint 目录也没有 ARF 标记文件。范围仅限已固定源码和现有资源，不据此断言作者其他版本没有实现。

原论文 Eq.19 的 `min(0, margin-distance)` 与正文“只在距离不足时排斥”的描述存在符号疑点；旧机制核对已记录。没有训练实现佐证时，不自行更正公式后称为完整 ARF 复现。

当前 `conv1` 噪声未被原版 AGA 删除，主要因为其 Attention/MLP 恢复不处理 `conv1`。公开投影仍能清理，MNIST 融合能力仍被保留。它是融合干扰现象，不是可靠抗 AGA 防御。

后续评价固定为：目标与伙伴的独立性能、真实融合性能、作者 AGA 后性能、公开清理后的同条件恢复结果。完整 Table 6 与 ARF 对照仍待补，不填写缺失数值。
