# 最后 MLP：区分函数删除与参数混合

固定诊断，不产生新保护权重，不改变已失败候选或调整其参数。公开整体替换反例仍成立。源码、协议、发布权重与父结果在运行前冻结；测试此前已观察，不称新留出集。

最后 MLP 只影响最终 CLS；Attention、LayerNorm 与此前各层相同。记融合前原专家的 MLP 为 f，发布函数为 f̃，δ=f̃−f。由已核验的 QuickGELU 分解，δ(x)=−B_J[e(A_Jx+b_J)−μ_J]。没有拟合。

使用作者 TA 的八个专家，β=0.2。原融合与保护融合的 MLP 为 F₀、Fᵣ。先验证所有区外权重及最终 CLS 输入逐位相同，再定义精确的加性余项 E(x)=Fᵣ(x)−F₀(x)−βδ(x)。它包括参数混合的全部非线性与跨因子项，不是小扰动近似。

四种诊断计算：

| 分支 | 最后 MLP 的 CLS 输出 |
|---|---|
| 原融合 | F₀(x) |
| 实际保护融合 | Fᵣ(x) |
| 只有函数差异 | F₀(x)+βδ(x) |
| 只有混合余项 | Fᵣ(x)−βδ(x)=F₀(x)+E(x) |

分别在 direct 与已保存的原作者 AGA 结果上计算。保留真实残差连接、ln_post、最终投影、归一化、目标 head；不能把准确率的差异相加，分类本身是非线性的。

**这两个干预读取已删除的原专家参数，是研究者 oracle。它们不是可发布防御、不是自适应攻击，也不声称执行 SLOA 或任意功能融合算法。**若函数差异分支几乎不降而混合余项下降，说明本候选的低融合性能主要来自参数表示；不能据此宣称不可逆任务信息破坏。如果函数差异有效，也仍须面对已实测的公开模块替换。

只测完整 DTD、MNIST；八专家参与不等于八任务均值或 Table6。8 次新全测试，8 行已复核父预测复用。原数组在服务器；本地与 GitHub 只留配置、计数、轻量代数指标和复核。

独立复核：全计数／标签／配对，16 行 fresh32 图预测；复核干预用完整原／发布 MLP 的 dense 函数相减，运行干预用被删偶响应公式，避免只复用同一公式。4 组同输入性与加性重建复跑，验证 source、17 个 checkpoint、发布及父原始数组指纹。
