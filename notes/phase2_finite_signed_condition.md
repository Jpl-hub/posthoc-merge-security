# 有限补偿与伙伴参数条件

2026-10-16。冻结O/B、PaRaMS与跨头诊断的事后机制研究。没有新发布变换、训练或超参数选择。

## 研究假设

需要检验的不是“AGA后还有差异”，而是：源端的任务保持、任务SVD探针与攻击后差异，是否已足以决定未知伙伴上的有限有符号分类损害？本轮用一个解析反例检验该蕴含，并在同一组512张合法MNIST训练图片上比较冻结方法的单分支和联合响应。

这512张图片沿用跨头诊断的构造索引，已经暴露，不作为新确认集。只读取目标专家、公开基座、冻结发布权重和既存的目标AGA权重；不读取SVHN或其他伙伴，不读取测试集，不运行新攻击。真实融合结论只引用既有冻结证据，不能据此选择新参数。

## 有限分类条件

CLIP末层LN、视觉投影和无偏置分类头可写成排序等价的分子

$$N(h)=hM+\sigma(h)b.$$

特征归一化与LN标准差是逐图片的共同正因子，不改变类别排序。原预测$y$与竞争类$c$的原间隔$g_{yc}=N_y-N_c>0$。给定有限发布变化$\delta N$，

$$H_{yc}=-\frac{\delta N_y-\delta N_c}{g_{yc}},\qquad \max_{c\ne y}H_{yc}>1$$

当且仅当原预测被严格改判（排除并列）。这比RMS或平均损失更直接，但只对已知实际环境可计算；分子的相对变化也不能混作原任务保持预算，后者仍用完整归一化分类分数。

对最后块的上游变化和下游$\delta B$，记原／改变上游后的MLP激活$Z_0,Z_1$，上游单独的完整块输出差为$U$，则

$$\delta h=U+Z_0\delta B^\top+(Z_1-Z_0)\delta B^\top.$$

源任务约束限制这些有限项的联合分类作用。真实融合改变了$Z$、上下游参数、LN和读出，因此需要的是各项在具体竞争类法向上的**有符号合计**，不能由源内抵消或单分支改判推断。此前O/B六项分解中，分类加权激活变化是实测主要损害项；该事实是既有伙伴上的事后解释，不是可用于新构造的伙伴先验。

## 解析反例：源端指标不决定伙伴上的符号

这是两个线性模块的说明性反例，不是CLIP防御、真实微调伙伴分布或完整AGA复现。仅使用作者AGA的逐列最小二乘投影分量，模型有两个输出类别；不包含MLP匹配、真实Attention或QuickGELU。通过精确分数运算和固定作者求解器分别核验。

固定

$$A_e=\begin{bmatrix}1&0\\0&1\\0&0\end{bmatrix},\quad
F=\begin{bmatrix}1&19/20\\19/20&1\end{bmatrix},\quad B_e=[F\ \ 0],\quad A_0=\tfrac45 A_e,\ B_0=B_e.$$

令$v=(3/10,3/10)^\top$、$d=(3/10,-3/10)^\top$，发布

$$A_r=\begin{bmatrix}I_2\\v^\top\end{bmatrix},\qquad B_r=[F-dv^\top\ \ d].$$

对**所有输入**都有$B_rA_r=F=B_eA_e$，因此完整归一化输出、所有任务SVD功能探针均保持，而非只在若干训练图片上拟合。原始参数距离

$$D^2=\frac{\|A_r-A_e\|_F^2}{\|A_e\|_F^2}+\frac{\|B_r-B_e\|_F^2}{\|B_e\|_F^2}<\tfrac14.$$

逐列对齐公开锚点$A_0$，理想最小二乘给出

$$\widehat A_e=\tfrac45 A_e,\qquad \widehat A_r=kA_r,\quad k=\frac{4/5}{1+(3/10)^2}=\frac{80}{109}.$$

攻击后$B_r\widehat A_r=kF$，独立分类及L2归一化输出仍保持；参数差异则非零。这里只应用A矩阵的逐列对齐，不能把本反例的数值写成“原版AGA准确率”。

伙伴族设$A_p=[sI_2;w^\top],B_p=B_e$，其中$s>0$。所有伙伴独立功能为$sF$，归一化后相同；与未保护目标融合也始终保持两个基准输入$e_1,e_2$的类别。用系数0.5融合保护模型与伙伴，有限输出精确为

$$B_mA_m=\gamma F+\frac14d(w-sv)^\top,\qquad\gamma=\frac{q+s}{2},$$

其中未对齐目标时$q=1$，对齐后$q=k$。伙伴也对齐时，把$(s,w)$同时乘以其逐列对齐系数（本例两列范数相等）。分类损害的符号与幅度由$w-sv$决定，它不由目标专家的源端保持性质决定。

固定两个伙伴：$(s,w)=(1,v)$与$(1,(-4/5,4/5)^\top)$。前者余项为零，后者余项可使两类均翻转。二者独立归一化功能相同，没有使用无限幅度参数。公开基座对应$(s,w)=(4/5,0)$，本例在目标对齐前后与基座均值都不改判。因此“公开基座没改判”也不能作为真实伙伴必然无效的证明。

反例只否定这些源端指标对该固定变换的普遍充分性；**不证明所有Post-hoc防御不可能，也不证明真实CLIP伙伴服从这个线性族。** 将此伙伴族直接当作优化环境会重新引入未经证明的分布假设，本轮不这样做。

## 对老师四条思路的含义

有意义的参数距离至少要通过AGA后的有限任务响应检验；SVD是维度正确的结构与探针工具，不能替代未知环境的$w-sv$或非线性版本。蒸馏可以约束联合源功能，却不提供未知伙伴的响应方向。

真正的融合极大极小还需要一个可辩护的伙伴参数／表示集合$\mathcal E$，例如

$$\max_{\psi:\,D\le0.5,\ R_{\rm task}\le0.5}\ \min_{e\in\mathcal E}\min_c\ \mathrm{finite\ signed\ class\ damage}(\psi,e,c).$$

这里写的是尚待证明与构造的问题，不是已实现算法。若集合允许本例的$w=sv$，该项不存在严格正的统一损害下界。排除它必须有可检验的环境条件，不能靠假想代理、放大预算或更多优化步骤完成。

## 固定验证

1. 用精确有理数核对所有模块乘积、逐列理想对齐、融合公式、预算和两个类别的严格间隔；固定作者求解器仅核对对应最小二乘分量的FP32误差。
2. 同一512张MNIST源训练图片、同一源完整前缀，对O/B、完整PaRaMS、预算内PaRaMS缩放消融、跨头点作末块分支干预；同时使用原专家与既存AGA原专家两种固定前缀。各方法的既存AGA参数只用于解释冻结点。
3. 统计上游、B单分支、联合的完整有限有符号间隔，保留全部类别和分数；另列完整归一化分数漂移。使用相同冻结任务SVD输入坐标检验B响应，A坐标不一致时不强行投影比较。
4. 每组固定16张原始图片做真实完整模型重放，检查末块重建与原模型前缀的差异。分支干预是分析，不冒充独立准确率、任务确认或真实融合。
5. 若只有源端配合和事后真实融合解释，尚无未知环境方向依据，则不构造新候选。全部旧模型保留。

### 功能预算更正

源O/B联合没有改判，但完整归一化分数的最坏相对间隔变化为**0.789630＞0.5**。独立NumPy定位后，用训练索引41538的原始图片直接运行原／保护完整模型，得到0.789627，重建分数误差7.89e-6。教师类别5、竞争类6、真值6，保护前后都预测5；原有预算没有排除教师误判图片，不能事后剔除这一见证。

因此，旧O/B在原有限确认集上的0.37623通过事实，以及独立99.71%、真实TA78.77%、原版AGA79.53%／77.85%均保持；但**不能继续宣称全任务最坏0.5约束已满足**。不修改O/B权重，不用此已暴露样本重新校正候选。新方法必须解决独立任务保持泛化与真实融合损害的兼容性。
