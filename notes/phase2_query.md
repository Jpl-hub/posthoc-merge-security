# Query取权与任务保持

这是一个待诊断候选。上一O路径保持了专家性能，但MNIST原版AGA融合仅下降0.09个百分点，已经关闭。它改变Attention取权后的线性读出；新的位置固定为同一最后block的Query，不扫描层。

## 计算机制

对某个头，CLS输出为

$$a(q)=\operatorname{softmax}(qK^\top/\sqrt{d_h}),\quad z(q)=a(q)V.$$

只改变$W_Q$、保持$W_K,W_V,W_O$，会改变注意力概率与读取的值，不能写成上一O路径的线性读出扰动。对于成对可逆Q/K表示变换，$W_Q^\top W_K$不变；Q单侧改变通常改变这个量。该区别不保证AGA失败，因为原作者算法可能通过锚点拟合改变模型功能；必须实测。

仍取任务矩阵$\Delta W_Q=W_{Q,e}-W_{Q,0}=U\Sigma V^\top$。用目标训练输入上的归一化分类方向响应选择32个单位Frobenius奇异模式，而非直接按奇异值大小认定重要。另一组目标训练数据只检查稳定性，不据其重新挑方向。发布变量为

$$E_Q=\|W_{Q,e}\|_F U_r C_Q V_r^\top.$$

将Query变化送入原softmax、原O、原LN2和原MLP，产生$h_0(C_Q)$。B仍在分类读出空间作统一解析蒸馏补偿$E_B=Q_cK_B$，保持同一分类充分统计、相同绝对正则和原始间隔容差。原专家冻结；没有类别标签训练或未来伙伴信息。

## 保持条件与验收

预算仍为$\|E_Q\|_F^2/\|W_{Q,e}\|_F^2+\|E_B\|_F^2/\|B_e\|_F^2\le0.5^2$。Q、B任务奇异输入探针与真实训练输入上的最坏相对间隔变化仍不超过0.5。Query输入探针只测试该线性算子的输入响应，K/V缓存固定；不宣称其覆盖全部自然图像或全部计算方向。

首先核验真实模型的Query/K/V缓存、softmax及下游分数；检查奇异响应、条件补偿梯度与有限步长。仅有可信可行方向才做冻结64步优化，独立确认失败不发布。若通过，再一次真实MNIST/SVHN TA和原AGA。DTD仅在真实目标任务有实质改善后验证。

这个候选不是Q/K补空间零响应噪声，不是Q/K成对函数保持重参数化，也不是参数预算扩大。可行性、真实融合效果和恢复边界尚未验证。
