# LayerNorm 未提高这三层的恢复代价

Cars 9–11 层的完整公开替换与三层闭式恢复已完成。连同 LayerNorm 一起替换后，结果与此前只替换 Attention／MLP 几乎相同。这是未保护教师的依赖检查，没有构造或验证新防御。

| 同一官方测试 | 原专家／原融合 | 完整三块公开替换 | 三次闭式恢复 |
|---|---:|---:|---:|
| Cars 独立，8,041 图 | 6,245 = 77.6645% | 5,342 = 66.4345% | 5,961 = 74.1326% |
| Cars 融合，8,041 图 | 4,990 = 62.0570% | 4,647 = 57.7913% | 4,844 = 60.2413% |
| MNIST 融合，10,000 图 | 9,400 = 94.00% | 9,402 = 94.02% | 9,400 = 94.00% |
| SVHN 融合，26,032 图 | 19,374 = 74.4238% | 19,382 = 74.4545% | 19,325 = 74.2356% |
| DTD 融合，1,880 图 | 981 = 52.1809% | 990 = 52.6596% | 981 = 52.1809% |

恢复后的 Cars 独立损失 3.5319 pp、融合损失 1.8157 pp，SVHN 损失 0.1882 pp。MNIST、DTD 准确率相同不代表逐图预测相同，配对变化见[完整结果](results.json)。八个专家参与 TA(0.2)，这里只测四个任务，不报八任务均值。

[此前保留 LayerNorm 的控制](../block_restore_gate_cars/summary.md)得到 Cars 独立 74.0953%、融合 60.2288%。新增完整替换仅使恢复后的融合多正确一张、独立多正确三张；没有显示归一化参数带来明显恢复障碍。此前 Attention／MLP 直接替换与新增完整替换的 Cars 独立／融合也都只差一张。这一结论限于当前 checkpoint 和三层区域，不能说所有 LayerNorm 或计算依赖都不重要。

[直接逐图比较](support_comparison.json)核实两轮的五条原模型预测完全相同。Cars 恢复后融合仅一张预测不同，独立九张不同（少正确两张、多正确五张）；这里没有用相近的总体准确率代替逐图检查。

攻击只用同一 256 张历史 Cars 训练图，查询原教师三个 block 输出，共 29,491,200 个标量；不是 256 个类别查询。公开归一化、Attention、MLP 上投影均不拟合；只对三个下投影及 bias 各作一次固定 ridge 闭式求解，没有梯度、搜索或真值标签。局部 block 拟合相对误差为 6.91%、10.14%、6.99%。区域历史选择用过目标训练标签。

对仅编辑这三块、架构及其余参数不变的发布，完整公开替换统一产生同一状态。因此 57.7913% 是这个限定支持族在当前融合下的恢复下限，其相对原融合的最大下降不超过 4.2656 pp。若发布还保留本攻击可见的 block 响应，固定恢复控制进一步给出 60.2413% 的条件下限。独立分类能力相近不能推出响应相同；这些数字不是对受保护模型已经测得的攻击结果。

源码 af3239c 在运行前冻结；运行 157.03 秒，独立复核 59.58 秒（求解与核验主体 59.15 秒）。三个 Cholesky 重算的正规方程相对残差不超过 4.53e-15，编译权重最大绝对差 7.75e-7；十五行计数、配对和各 128 图前缀全部通过。[协议](../block_restore_norm_gate_protocol.md)、[指纹及元数据](metadata.json)、[独立核验](validation.json)。28 MB 恢复张量和原始预测仅在服务器。

这项遗漏已补齐，停止该三层支持上的仿射绑定、秩或强度搜索。下一构造须改变任务信息的恢复代价，并说明为何可观察功能不能用同一公开基重建；单纯增加绑定模块不构成机制依据。
